# ASCENSION

**Canonical game repository:** this repository  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/  
**Play:** https://joenasr.itch.io/ascension

ASCENSION is an isometric architectural puzzle game built around spatial routes, rotating structures, moving platforms, switches, alignment and perspective.

## Game identity

This is the primary public source repository for the ASCENSION game lineage.

Older or packaging-specific repositories are retained as development history and backups:

- `Joenasriani/ascension` — earlier application build
- `Joenasriani/the-ascension-game` — earlier application build
- `Joenasriani/ascension-opt-playstore` — Android / Play Store packaging and QA branch of the same game lineage

Those repositories are not separate games.

## Gameplay

Guide the traveler through compact floating structures by reading the level geometry, rotating the view, operating mechanisms and creating a valid route to the goal.

Core mechanics include:

- architectural path puzzles
- rotating bridges and structures
- sliding platforms
- switches and route changes
- perspective based navigation
- desktop and touch controls

## Technology

Three.js browser game optimized for desktop and mobile play.
