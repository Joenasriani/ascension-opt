ASCENSION – Privacy Policy

Effective: November 22, 2026

This policy describes the ASCENSION Android game distributed by Quest ReQuest (developer contact: questrequestvr@gmail.com).

Gameplay and accounts

ASCENSION is a single-player architectural puzzle game. The Android wrapper does not require an account, and does not include an advertising or developer analytics SDK. No account-registration or in-app purchase system is provided in the current Android wrapper.

Network requests

The game includes bundled gameplay assets, but some web runtime dependencies, styles and fonts are fetched from third-party services when the game loads, including aistudiocdn.com, cdn.tailwindcss.com, and Google Fonts services. Those services may receive technical connection information such as your IP address, user agent, and request information under their own policies. A network connection may be required to start or play the game.

Local storage

The app's embedded web environment may use device-local browser storage or caches for game data and web resources. You can remove local app data using Android's app settings or by uninstalling the game.

Information sent to the developer

The Android wrapper does not implement a developer-operated account or telemetry endpoint. If you email the developer for support, your email address and message will be used to respond to your request.

Children

ASCENSION is not specifically designed for children. Children should use the game with appropriate parental guidance. No advertising SDK is included.

Changes

This policy may be updated if game functionality or third-party dependencies change. The effective date above will be updated.
